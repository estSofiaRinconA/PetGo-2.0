Cómo administrar PetGo

Esta guía explica el manejo cotidiano de solicitudes y horarios. Solo está disponible después de comprobar que tu cuenta tiene permisos administrativos.

1. Consultar solicitudes

  1. Abre Solicitudes de servicio.
  2. Utiliza Activas para ver reservas pendientes y confirmadas.
  3. Utiliza Historial para revisar las completadas y canceladas.
  4. Selecciona Actualizar lista para obtener el estado más reciente.

2. Confirmar y completar

  1. Comprueba la mascota, servicio, fecha y hora de una solicitud pendiente.
  2. Confirma la reserva solo cuando puedes atenderla.
  3. Después de prestar el servicio, márcala como completada.
  4. Verifica el resultado en la lista o el historial.

3. Configurar la agenda

  1. Entra a Configurar agenda.
  2. Revisa los días de atención y las horas de apertura y cierre.
  3. Configura duración y capacidad de cada modalidad.
  4. Pulsa Guardar reglas para guardar los cambios en Supabase.

4. Seguridad y sesión

  1. Utiliza solo cuentas autorizadas como administradoras.
  2. No compartas credenciales, contraseñas ni códigos.
  3. Al terminar, pulsa Cerrar sesión en el panel.
  4. Si un cambio no aparece, actualiza la lista antes de repetirlo.

Importante: los horarios configurados no realizan todavía un cálculo completo de cupos por solapamientos de duración. Confirma manualmente la disponibilidad antes de aprobar una solicitud.

Estados de las reservas

Pendiente: recibida, aún no aprobada. Confirmada: aceptada por administración. Completada: servicio finalizado. Cancelada: solicitud cancelada; permanece en el historial.

Cuando hay un problema

Si ves «Sin permisos», vuelve al inicio de sesión con una cuenta autorizada. Si la API no responde, revisa que el servicio de Render esté activo. Si no llegan correos, revisa los registros de Supabase Auth y SMTP. No utilices el panel para cambiar permisos de usuarios: ese proceso pertenece a la administración técnica de Supabase.
